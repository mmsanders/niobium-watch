# Niobium Watch

**Live:** [https://mmsanders.github.io/niobium-watch/](https://mmsanders.github.io/niobium-watch/)

Static choke-point dashboard for Brazil-dominated niobium / ferroniobium supply. Watch-kit sections 1–4 + dominant temperature banner (section 5).

## Data
- `data/meta.json` — status, `watch_kit`, choke sites, curated signals
- `data/exports.json` — Brazil FeNb export baseline (Comex Stat)
- `data/headlines.json` — live RSS headlines (refreshed by Actions)

## Automation
GitHub Actions refreshes headlines twice daily (token-free) and deploys Pages.

**Pages URL:** https://mmsanders.github.io/niobium-watch/
